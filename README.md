The Student Utility App is a simple menu-driven Java console application designed to help students practice basic Java programming concepts such as methods, conditionals, loops, and user input handling.
The application allows users to perform common utility operations like arithmetic, number checking, and displaying information based on user choices.

Features

The application provides the following options:

1. Add two numbers
Takes two integers from the user and displays their sum.

2. Check if a number is Even or Odd
Determines whether a given integer is even or odd.

3. Print numbers from 1 to N
Displays all numbers from 1 up to a user-entered number.

4. Display days of the week
Shows the corresponding day of the week based on a number (1–7).

5. Exit the application
